About Order the Album

Order the Album is an independent music trivia game about remembering how albums unfold from the first track to the last.

Why this project exists

Many music quizzes ask listeners to identify an artist, recognize a song, or answer a fact about a release. Order the Album focuses on a different kind of listening memory: knowing where each track belongs in an album's sequence.

The idea is simple. Choose an artist, choose an album, arrange the tracks, and check how many tracks occupy their correct positions. The game is designed for casual listening fans as well as people who know their favorite records in detail.

How to use the game

  1. Choose an artist from the collection.
  2. Select an album.
  3. Arrange the displayed tracks in the order used by the game.
  4. Submit your answer to see which positions were correct.
  5. Try another album or share your result.

About the album data

The game uses a defined tracklist for each entry so that each challenge has a consistent answer. Album editions and regional releases can differ, so the edition selected for a game matters. If you notice a tracklist or album-information error, please contact the site maintainer with the album name, the entry you believe is incorrect, and a reliable source that supports the correction.

The collection is an ongoing project. Information should be checked and corrected as the site develops; this page does not claim that every entry has been independently verified unless that work has actually been completed.

Independent project

Order the Album is an independent project and is not affiliated with or endorsed by the artists, record labels, or music services mentioned on the site.
